# 硬件接线与上电检查

> 注意：这是早期单CAN/双步进版本的历史说明。当前接线请看根目录
> `README_双CAN新版本.md`，以下表格不能用于本次双CAN混合机构版本。

引脚图见同目录 `DM_MC02引脚图.png`。

## MC02 资源分配

| 功能 | STM32H723 资源/引脚 | 接法或说明 |
|---|---|---|
| CAN1 RX/TX | PD0 / PD1 | 经板载 CAN1 收发器，从 CAN1 插座接 CAN_H、CAN_L |
| CAN2 RX/TX | PB5 / PB6 | 初始化并启动，但当前没有业务设备 |
| USB CDC | PA11 / PA12 | 电脑 USB-A → 数据线 → MC02 Type-C |
| BMI088 | 板载 SPI2 | 板内连接，不接外部线 |
| BMI088 加热 | PB1 / TIM3_CH4 | 板内连接 |
| STEP1 | PA0 / TIM2_CH1 | 接步进驱动器 1 的脉冲输入 |
| STEP2 | PA2 / TIM2_CH3 | 接步进驱动器 2 的脉冲输入 |
| DIR1 | PE7 | 从 UART7 接口的 RX 脚引出 |
| DIR2 | PE8 | 从 UART7 接口的 TX 脚引出 |
| 启动按钮 | PE2 | 从 UART10 接口 RX 脚，经常开复位按钮接 GND |
| 舵机信号 | PE9 / TIM1_CH1 | 50 Hz PWM，接舵机信号线 |
| 舵机电源 | 板载 5 V/GND | PC15 拉高使能 5 V，舵机持续供电 |

PE7/PE8 和 PE2 已分别从 UART7、UART10 改为普通 GPIO，因此固件不会初始化这两个
串口。按钮只接 PE2 和 GND，不向 PE2 输入 5 V；内部上拉后松开约为 3.3 V，按下为
0 V。

## CAN1 电机分配

CAN 波特率为经典 CAN 1 Mbit/s、11 位标准帧。五个电调并联在同一 CAN1 总线上：

| 反馈 ID | 电机 | 用途 | 控制帧 |
|---|---|---|---|
| `0x201` | M2006 #1 | 底盘轮 1 | `0x200` 的第 1 路 |
| `0x202` | M2006 #2 | 底盘轮 2 | `0x200` 的第 2 路 |
| `0x203` | M2006 #3 | 底盘轮 3 | `0x200` 的第 3 路 |
| `0x204` | M2006 #4 | 底盘轮 4 | `0x200` 的第 4 路 |
| `0x205` | GM6020 | 机构旋转电机 | `0x1FF` 的第 1 路 |

总线两端各保留一个 120 Ω 终端电阻，整车断电后在 CAN_H 与 CAN_L 之间应测到约
60 Ω。所有电调和 MC02 必须共地，CAN_H/CAN_L 不要接反。

## 两套步进驱动器

代码输出约 12.66 kHz、约 50% 占空比的 STEP 脉冲；`CCR=0` 时停止。ENA 按已确认
方案在驱动器外部固定为使能，不占 MC02 引脚。

DM420 类驱动器有多种输入接法，接线前以你手中驱动器外壳/说明书为准：

- 若 PUL/DIR 输入明确支持 3.3 V 单端信号，可把 MC02 GND 与驱动器信号地共地，
  PA0/PA2 接 PUL，PE7/PE8 接 DIR；
- 若是 5 V 光耦输入或要求较大输入电流，不要直接赌 3.3 V GPIO，增加四路
  3.3 V→5 V 缓冲/开集电极驱动，再接 PUL±、DIR±；
- 步进电机相线和驱动器电源不能接到 MC02 GPIO/5 V 口，必须接驱动器的 A±、B±
  和独立电机电源。

当前没有原点/限位开关。首次运行前须把两轴人工移到代码认为的 `StepCounter=0`
位置，并保证软件动作范围不会撞机械端点。

## 舵机

PE9 输出 TIM1_CH1，计数频率 1 MHz、周期 20 ms。业务代码保持学长参数：

- `2500 us`：`Grab_Compare`；
- `2400 us`：`Put_Compare0`；
- `2200 us`：`Put_Compare1`。

这些脉宽明显靠近常见舵机范围的上端，第一次测试必须先拆掉负载或解除连杆，确认
舵机不会顶死后再装机构。

## 推荐上电顺序

1. 先不接电机动力电源，只给 MC02 上电并烧录；
2. Type-C 接电脑，确认出现 `/dev/ttyACM15`；
3. 调试器观察 `ImuReady=1`，静止时 `Now_Omega` 接近 0；
4. 手动转动板子核对 `Now_Yaw` 正负和多圈连续性；
5. 只接 CAN 和一个悬空轮，核对 ID、反馈速度与控制方向；
6. 再逐个加入其余电机、步进驱动器和舵机；
7. 最后才允许按 PE2 启动完整自动流程。
